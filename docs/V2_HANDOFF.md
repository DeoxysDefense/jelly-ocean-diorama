# Jelly Ocean Diorama — V2 交接文档（给下一个 AI Agent）

> 版本：基于 **v1.1**（`package.json` 1.1.0，GitHub `main` 提交 `7efd3cc`）。
> 读者：接手 V2 开发的 AI 编程 Agent。用户（项目所有者）用中文沟通。
> **V2 范围已经和用户讨论确定**，见 §9–§13。最后一节是**可以直接粘贴给新 Agent 的启动 Prompt**。

## 0. 一句话 + V2 的灵魂

一个用 Three.js + TypeScript + Vite 写的「果冻海水微缩海洋」：2.5D 正交相机、透明果冻水体、左侧热带小岛、
自主行动的海洋生物、沙盒编辑、昼夜潮汐、漂流瓶、小游戏。它同时是 **Lively Wallpaper 交互式桌面壁纸**、
**桌面快捷方式小程序**（Edge app 模式）和普通网页。所有模型 / 贴图都是**代码程序化生成**，没有外部资源。

设计哲学（v1 起）：**A peaceful ocean that feels alive, rewards curiosity, and offers small moments of play.**

**V2 用户亲自定下的核心原则（比任何功能都重要）：**

> **这是一个「偶尔去看看」的地方，不是一个「需要管理」的地方。**
> 用户在休息、或在电脑前短暂分心时打开它，得到片刻平静和放松，然后回去继续工作。
> 它是注意力的短暂切换，**不能制造「要一直盯着 / 要回来 check-in」的冲动**。

由此推出的硬规则（每个 V2 功能都要用它检验）：

1. **离开不会变坏**：没有饥饿、死亡、枯萎、污染惩罚；什么都不需要「维护」。
2. **不会因为没看见而错过**：你不在时发生的事会留下痕迹或记录（见 §11、§12），不会消失。
3. **没有完成度**：不显示「12 / 30」、百分比、进度条、剪影、稀有度星级、成就、连续签到。
4. **不打扰**：不弹通知、不闪红点徽标、不催你回来；所有新内容都是「你去看时才发现」。
5. **有限是特色**：世界是一个有边界的「鱼缸」，不做无限地图。
6. **本轮不做分享**：不做分享链接、世界文件导出分享、截图、拍照 / 明信片模式（用户明确否决，见 §9.3）。

## 1. 必须遵守的硬性约定

1. **不推翻已有功能**。在现有架构上扩展；不换技术栈（Three.js r170 / TS / Vite 5 / Vitest，无 UI 框架）。
2. **Front View 构图是神圣的**：小岛偏左、小木屋、天空 / 海水 / 海床比例。改动世界尺寸或相机前先截图对比。
3. **不打扰**：不自动弹窗、不自动开始小游戏、不播放突兀音效。随机内容低频、可关闭。
4. **Lively 兼容**：壁纸是 `file://` 加载的单文件 IIFE（不能用 ES module 的动态加载）；Ambient 模式低资源；
   `livelyWallpaperPlaybackChanged` 暂停时完全停渲染。新设置要同步加到 `lively/LivelyProperties.json`
   和 `src/platform/WallpaperAdapter.ts`。
5. **存档向后兼容**：改存档结构就升 schema 版本并写迁移（见 §5）。旧存档里的物体不能位移。
6. **所有资源程序化**；若引入外部资源，必须在 `ASSETS.md` 记录来源和许可证。
7. **新功能的文字双语**（中文 / English），走 `src/features/i18n.ts`；旧面板目前仍是英文。
8. **每次交付前**：`npm test`（类型检查 + 单元测试）、`npm run build`、`npm run package:desktop`
   （同时生成 Lively 包和桌面包）全部通过；并在浏览器里**实际看过画面**。
9. 不要把占位实现当成完成；做不到的要明说。
10. 给用户的回复用中文：说清楚 **原因 → 修复 → 怎么验证的 → 还没验证什么**。
11. **不要 commit / push**，除非用户明确要求。仓库已配置本地提交邮箱（GitHub noreply），不要改 git 配置。
12. 每个新功能都先用 §0 的核心原则检验：会不会让人想一直盯着、会不会需要管理？会的话改设计或先问用户。

## 2. 运行与构建

```bash
npm install
npm run dev              # http://127.0.0.1:5173
npm test                 # tsc + vitest（当前 28 个测试）
npm run build            # tsc + vite build → dist/
npm run package:lively   # 单文件壁纸 → dist-lively/ + JellyOcean-Lively.zip
npm run package:desktop  # 上面 + 桌面版 → dist-desktop/ + JellyOcean-Desktop.zip
npm run demo:video       # 渲染约 1 分钟的玩法演示视频到 demo/（需要 Edge；见 §6 末尾）
```

- `.claude/launch.json` 有两个预览配置：`jelly-ocean`（dev，5173）和 `lively-build`（预览 dist-lively，5174）。
- **Lively zip 的文件必须在压缩包根目录**（`LivelyInfo.json` 在最外层）。`scripts/zip.mjs` 是自写的 zip 生成器，
  不要换回 PowerShell `Compress-Archive`（曾因路径转义把整个文件夹打进去，导致 Lively 拒绝导入）。
- 桌面版：`dist-desktop/create-shortcut.ps1` 创建桌面 + 开始菜单快捷方式，目标是
  `msedge.exe --app="file:///…/index.html"`；图标由 `scripts/icon.mjs` 程序化绘制（PNG / ICO）。
  用户本机的快捷方式指向 `D:\AI_ISLAND\dist-desktop\`，重新打包后自动生效。

## 3. 坐标与世界

- **X** 左右（`xMin -30` … `xMax 30`），**Y** 高度（静水面 `y = 0`），**Z** 纵深：前切面 `zFront = 6`，
  后墙 `zBack = -13`（v1 中已从 -6 扩展到 -13，Top View 才有真正的纵深）。
- 用 `src/config.ts` 里的 `zClamp(z, margin)`、`randZ(margin, bias)`、`zCentre()`，**不要再写死 ±5 之类的数字**。
  `randZ` 的 `bias > 1` 偏向前半部分（保持 Front View 生动，后方稀疏）。
- 地形：`H(x,z) = base + sed`；`sed` 里有 `firm`（Island Stamp 压实层，不会滑塌）。网格约 0.2 单位
  （`TerrainSystem.nz` 由纵深自动算）。
- 水面：`W(x,z,t) = level（潮位）+ 波动方程模拟 + 解析风浪 + 微涟漪`，统一由 `WaterSurfaceSimulation.heightAt()` 提供。
  **Front 和 Top View 共用同一个 3D 高度场**——所有漂浮物、溅水都要用它。
- 相机：`CameraManager` 一个正交相机在 Front（俯角 7.2°）和 Top（90°）之间插值；`cam.isTop`、`cam.blend`。

## 4. 架构速览（`src/`，约 1.6 万行）

| 目录 / 文件 | 职责 |
|---|---|
| `core/App.ts` | 根对象：持有所有系统，`step(dt)` 主循环顺序，`render()`；V3 的 `prefs / i18n / mail / coconuts / events / magnifier / games / spray`；`serializeExtras / applyExtras`（存档扩展）；`busy`（编辑或小游戏中，随机事件延后） |
| `core/RenderPipeline.ts` | 三 pass：世界 → HDR MSAA RT（含深度）→ 合成到画布（写 `gl_FragDepth`）→ 水体最后画（自己做折射 / 吸收 / 菲涅尔，输出不透明）。`render(world, water, cam, target)` 可渲染到离屏目标 |
| `core/EnvironmentController.ts` | 风、水色预设、时间（手动 / 循环 / 跟随电脑时钟）、雨、潮位（手动 / 自动潮汐），产出 `atm`（大气参数） |
| `water/*` | 水面模拟（**子步数按 CFL 自适应**，防卡顿时爆出尖刺）、风浪、水体渲染 shader、水色 |
| `world/*` | 地形、天空、光照、小岛（木屋、2 棵椰子树 `palms[]` 含 `spine` 与 `shake`）、礁石 / 珊瑚 / 栖息地（`Reef`）、水流场 `FlowField`（水流场，植物 shader 取 8 个分散的射流点）+ `CurrentStreaks`（可见的水流线）、粒子、沉积、浮游生物荧光、雨、漂浮物 |
| `world/coralFactory.ts` | 所有程序化珊瑚 / 贝壳。`conch()` 是 Raup 螺旋模型（各圈相互覆盖，闭合螺塔），`geometry.userData.aperture` 记录壳口中心 / 朝向 / 螺轴 |
| `creatures/*` | 鱼群（boids + 心情 / 饥饿）、水母、螃蟹、寄居蟹（自动对齐壳口 `orientShell()`、换壳）、章鱼（含 **捉迷藏游戏模式** `gameHide / gameFound / gameEnd`）、鳐鱼（水深带 `band()`，永不出水）。`shoreline.ts`：螃蟹类永不上岸 / 搁浅自救 |
| `features/*` | V3 功能：`Prefs`（自动持久化）、`i18n`、`OceanMail`（漂流瓶）、`CoconutGrowth`（真实时间戳生长）、`OceanEvents`（随机小惊喜，`OceanEvent` 接口）、`Magnifier`（第二次实时渲染）、`MiniGames` + `StoneSkipping` + `HideSeek`（`MiniGame` 接口）、`fx.ts`（`floatStep` 浮力 / `Spray` 水花池 / `disposeTree`） |
| `content/messages.ts` | 漂流瓶消息库：24 冷知识 + 30 幸运句 + 20 温柔句，双语，稳定 id，`pickMessage(recent)` 避免重复 |
| `interaction/*` | 工具状态、撤销重做、选择 / 拖拽、`InteractionManager`（指针 → 世界映射 + **输入优先级**）、地面光圈 |
| `ui/*` | `UIController`（Ocean Studio 五个标签页）、`FeatureUI`（V3 折叠组 + 漂流瓶纸条）、`styles.css`（颜色 token 在 `:root`）、内联 SVG 图标 |
| `platform/*` | `WallpaperAdapter`（Lively / Wallpaper Engine 属性）、`Settings`（基础设置）、`WorldStore`（存档 v3 + 迁移） |
| `util/shaders.ts` | `patchMaterial()`：给标准材质注入焦散、摇摆（**水流只影响水下植物**，`org.y < uWaterLevel`）、边缘光、程序化凹凸；`shared` 全局 uniform |

**输入优先级**（`InteractionManager`）：UI（DOM，不进画布）→ 进行中的小游戏（独占指针 / 滚轮）→ 放大镜固定 /
漂流瓶 / 椰子与椰子树 → 当前工具 → 环境悬停。一次按下只交给一层（`captured` 字段）。新增可点击物体请加在第 3 层，并只在
`tool === 'default'` 或 Ambient 模式下响应，避免和编辑工具冲突。

**主循环顺序**（`App.step`）：环境 → 相机 → 交互 → 水流 → 水面模拟 → 地形 / 遮罩 → 光照 / 水体大气 → 天气 / 漂浮 / 浮游生物 →
沉积 → 生物 → 小岛 → 选择 → 气泡 / 雪 → 水体 → 天空 → V3（椰子、漂流瓶、事件、小游戏、水花、面板计时）。

## 5. 持久化与存档

- **基础设置**：`localStorage['jelly-ocean-settings-v1']`（水色、风、模式、画质、面板折叠）。
- **V3 偏好与慢速状态**：`localStorage['jelly-ocean-v3']`（语言、漂流瓶 / 小惊喜开关、频率与倒计时、椰子时间戳、
  个人纪录），由 `features/Prefs.ts` 自动保存；`merge()` 会校验每个字段（导入的脏数据不会污染）。
- **Save World 槽**：`localStorage['jelly-ocean-world-v2']`（键名历史原因未改），内容是 **schema v3**：
  沙子网格（自带 `bounds`）、物体、放置的栖息地、种群、环境、`extras.prefs`。
  `WorldStore.migrateGrid()` 按世界坐标把旧网格重采样到新网格——**以后再改地形范围或分辨率，复用它**。
- 临时状态（涟漪、水花、进行中的事件、漂流瓶、掉落的椰子、石头）**永不存档**。
- 计时类功能用**时间戳**（离线时间按上限补算，不回放动画）；随机事件 / 漂流瓶用**有效运行时间**（页面隐藏或壁纸暂停不累计）。

## 6. 调试与验证方法（非常重要，省时间）

浏览器控制台里 `window.__jelly` 就是 `App`：

```js
const a = __jelly;
a.setPaused(true);                 // 停止 rAF 循环，改为手动步进
for (let i = 0; i < 300; i++) a.step(1/30, false);  // 模拟 10 秒
a.render(false);                   // 手动渲染一帧（射线拾取前也要先 render，矩阵才更新）
a.debugView(x, y, zoom);           // 放大到世界坐标 (x, y)；无参数复位
a.mail.spawnTest();                // 立刻生成漂流瓶
a.events.trigger('starfish' | 'school' | 'crabShell' | 'palmLeaf' | 'shellAshore');
a.games.start('skip' | 'hide');  a.games.exit();
a.creatures.setPopulation('octopus', 1);
a.renderer.info.memory             // 泄漏检查：循环跑功能前后比较 geometries / textures
```

经验：
- 预览面板里的 rAF 会被节流，**别依赖实时运行**，用 `setPaused + step` 做确定性测试；截图偶尔是旧帧，`render` 后再截。
- Front View 里把画面中心对准某点：`debugView(p.x, p.y - p.z * tan(7.2°), zoom)`。
- 单独看一个模型：新建 Scene + 克隆光照 + 正交相机直接 `renderer.render`（v1 调寄居蟹贝壳就是这样做的）。
- **用户可能正在用同一个预览标签页**——检查前开一个后台标签页，用完复原（不要暂停 / 缩放用户的画面）。
- 内置浏览器打不开 `file://`；验证单文件包可用无界面 Edge：
  `msedge --headless=new --user-data-dir=<临时目录> --use-angle=swiftshader --enable-unsafe-swiftshader --virtual-time-budget=10000 --dump-dom file:///…/index.html`
- 长时间稳定性：v1 用「每类功能循环触发 15 分钟模拟时间」测过，V3 功能显存零增长。新增临时对象必须有明确生命周期并 dispose。
- 性能参考（1.5 像素比、1280×720）：一帧约 13 ms；放大镜开启约 +3 ms；水面模拟约 2–3 ms。
- 截图 / 录屏工具（`scripts/demo/`）：`node scripts/demo/shoot.mjs <脚本.js> <输出目录>` 用无界面 Edge 加载
  `dist-desktop/index.html`，脚本里可用 `app` 和 `await shot(name)`——P1 的构图对比截图很适合用它。
  `scripts/make-demo-video.mjs --stills=13,24` 只渲染演示视频里的几个时刻。演示脚本 `scripts/demo/director.js`
  依赖 v1 的世界坐标，世界扩展后它的镜头位置可能需要更新（不是 V2 的必做项）。

## 7. 已知限制 / 技术债

- 只有 V3 新功能是双语；主面板仍是英文。
- 漂流瓶 / 小惊喜按有效运行时间计时，壁纸常暂停时会很稀少（有意为之）。
- 默认 Front View 下部分椰子被树叶挡住，摇树是更可靠的采摘方式。
- 打水漂是简化的弹跳规则（入水角 < ~29°、水平速度 > 2、每次能量损失），没有石头自旋 / 倾角模型。
- 捉迷藏在 Front View 只选 z > -6.5 的藏身处（太远会被水色遮住）。
- 鱼的游动变形不进阴影 pass；沙子网格精度约 0.17×0.2；水只是表层高度场，没有 3D 流体体积。
- Lively 的鼠标交互依赖宿主转发，桌面图标会挡住点击。
- 还没做：音频（必须可选、默认关）、鸟、自由旋转视角、Wallpaper Engine 打包、Lively 缩略图（`lively/thumbnail.jpg`，打包脚本会自动带上）、LICENSE（等用户决定）。
- 用户之前说过「暂不」的：GLB 模型替换、Follow Creature 跟随镜头。
- v1 需求里明确排除过的：海底收音机、时间胶囊、实时新闻 API、真实天气同步、海洋明信片、复杂社会 / 繁殖系统、大型任务 / 成就 / 排行榜。
  **如果 V2 想做其中任何一项，先问用户。**

## 8. 做 V2 的工作方式（建议）

1. 先读 `README.md`、`ASSETS.md`、本文件，再看相关源码；不要只写计划。
2. V2 范围已确定（§9–§13），按 P1 → P4 分阶段做，每阶段可运行、可验证，做完汇报并等用户确认。范围外的想法先问用户。
3. 新系统尽量做成 `features/` 下的独立模块，在 `App` 里注册；需要 UI 就加在 `FeatureUI` 的折叠组里，保持面板简洁。
4. 改存档 → 升 schema + 迁移 + 测试；改世界尺寸 → 复用 `migrateGrid` 并对比 Front View 截图。
5. 交付时更新：`README.md`（功能 / 控制 / 已知限制）、`ASSETS.md`、`package.json` 与 `lively/LivelyInfo.json` 的版本号。
6. 回复用户：中文；先结论，再原因 / 修复 / 验证；明确说哪些没测（比如「没在 Lively 里实测」）。

## 9. V2 范围（已与用户确定）

### 9.1 四个阶段（按顺序做，每阶段可运行、可验证，做完向用户汇报并等确认再进下一阶段）

| 阶段 | 内容 | 章节 |
|---|---|---|
| **P1** | 世界扩展成有边界的微型群岛 + 三种镜头（Full / Focus / Top） | §10 |
| **P2** | 海洋日记 Ocean Journal：世界记忆 World Memory + 我的海洋 My Ocean（解决 Undo / Reset 同步） | §11 |
| **P3** | 稀有访客 + 观察手记 Field Notebook（不显示总数、不显示剪影） | §12 |
| **P4** | 岛屿种子（Island Builder 缩小版）：选海域 → 放种子 → 自己慢慢长 | §13 |

P1 是地基（其余功能都依赖新地图），必须先做且做稳。

### 9.2 用户已同意的方向
- 有限但更自由的海洋沙盒：扩大**可创造的空间**，不扩大**世界的尺度感**；保留鱼缸感。
- 保留主岛（小木屋 + 两棵椰子树），新增副岛、礁区，并**刻意留出一大片空白水域**带来宁静。
- 图鉴改为「自然观察发现」，不是捕捉；**不显示总数、不显示剪影**，但开发侧必须有完整的物种表和出现频率（§12.2）。
- 操作记录与世界记忆分开（§11）。

### 9.3 用户明确**不要**的（不要做，也不要「顺手」加）
- 任何分享：分享链接、世界码、导出世界文件给别人、截图按钮、拍照 / 明信片模式、录屏导出。
- 图鉴里的剪影、总数、完成度、稀有度标签；任何任务、成就、排行、每日签到。
- 大型 Island Builder（城市建造 / 经营），留到以后再讨论。
- v1 就排除的：海底收音机、时间胶囊、实时新闻 API、真实天气同步、复杂社会 / 繁殖系统。

### 9.4 可选候选池（**没有被选中**，想做必须先问用户）
呼吸潮汐（可选模式，浪和潮按很慢的呼吸节奏起伏）、离开后回来的轻微痕迹（沙纹变化、冲上岸的贝壳）、
夜光浪花、鱼的记忆（固定时间喂鱼会提前聚集）、椰子章鱼、寄居蟹排队换壳、潮池、生态小循环、
海鸟、风暴后彩虹、小鱼躲水母伞下、可选环境声景（默认关）。

## 10. P1 — 世界扩展：有边界的微型群岛

### 10.1 尺寸（用户定的比例）
- **X 方向 ×1.7**：现在 `xMin -30 … xMax 30`（宽 60）→ 约 `-51 … 51`（宽 102）。
- **Z 方向 ×1.5**：现在 `zFront 6 … zBack -13`（深 19）→ 深约 28.5。
  建议**前切面 `zFront` 尽量不动**（保住 Front / Focus View 的构图），主要往后扩到 `zBack ≈ -22.5`；
  如果截图对比后发现需要微调前切面，可以小幅调整，但要说明理由。
- 面积约为现在的 **2.5 倍**。这比讨论时的「2 倍左右」略大，是用户有意选的（Z 想更宽）。
- 一律通过 `CONFIG.world` + `zClamp / randZ / zCentre` 等工具函数；**全工程搜一遍写死的 ±30、-13、6 等数字**。

### 10.2 鱼缸感
- 世界四周的边界要**看得见、好看**：果冻水体两端和后墙保留圆角厚边、折射边缘；
  Full View 下整块海洋像放在桌上的透明微缩模型。
- 不做无限地图、不做无缝滚动；镜头不能拍到世界之外的「空白」。

### 10.3 布局
- **主岛**：现在的岛（小木屋 + 两棵椰子树）保持原样，作为主岛。
- **副岛 2–3 个**（程序化生成，风格统一）：
  - 潮间沙洲：低潮露出、高潮淹没（直接用现有潮位系统）；
  - 礁石小岛：几块深色岩石 + 少量植被，以后海鸟可以落脚；
  - 微型山岛：小小的陡峭火山 / 山体，顶上一点绿色。
- **礁区**：1–2 片珊瑚和礁石区域，复用 `Reef` / `coralFactory`。
- **一片开阔的安静水域，占世界约三分之一**：几乎不放物体、生物稀疏；建议加一个**蓝洞 / 深水落差**，
  让开阔水域有深浅对比，显得宁静而不是「空」。
- 生物活动范围按新布局重新分区，但**主岛附近的生物密度要和 v1 一样**（Focus View 看起来不能变冷清）。

### 10.4 三种镜头
| 镜头 | 作用 | 交互 |
|---|---|---|
| **Focus View**（默认，也是壁纸默认） | 保持 **v1 现在的镜头尺度**，精致的局部 | 拖动平移（如：右键 / 中键拖动，或按住空格拖动）、方向键、双击聚焦某处、小地图点击跳转；可选非常慢的自动漂移 |
| **Full View** | 看整个鱼缸 / 群岛 | 只看 + 正常的点击互动；从这里双击某处 → 平滑推进到 Focus View |
| **Top View** | 俯视地图，编辑 | 滚轮缩放、拖动平移；现有 X–Z 编辑工具照常工作 |

- 现在 Front ↔ Top 的插值（`CameraManager.blend`）要扩展为三种状态之间的平滑过渡。
- **Focus View 打开时的默认取景必须和 v1 的 Front View 一模一样**（用截图对比验证）。
- 镜头位置写进设置持久化；Lively 属性里加「默认镜头 / 自动漂移」选项。
- 编辑工具、射线拾取、放大镜、小游戏、漂流瓶在三种镜头下都要验证。

### 10.5 性能与存档（风险点，先测量再优化）
- 水面模拟、地形网格、沉积的开销**和面积成正比**，面积 ×2.5 ≈ 开销 ×2.5。
  先测量；可选方案：远离镜头的区域降低模拟精度 / 降低更新频率、视野外的生物降频更新、实例化。
- 目标：Focus View 下帧时间不超过 v1 的 +30%；Lively Ambient 模式要单独测。
- 存档：升 schema（v3 → v4），用 `WorldStore.migrateGrid()` 把旧沙子网格按世界坐标重采样到新网格；
  **旧存档里的物体位置不能变**；补迁移测试。

## 11. P2 — 海洋日记 Ocean Journal

一个可展开 / 收起的侧边日记（放在面板旁，默认收起，双语）。里面三个部分：
**世界记忆**、**我的海洋**（本阶段）、**观察手记**（P3 加入）。读起来像日记，不像系统日志：
按天分组，每天几行，语气温柔简短，例如「傍晚，一座小沙洲从浅滩里冒了出来。」

### 11.1 世界记忆 World Memory —— 这片海见过的事
- 记录：稀有访客来过（看见或没看见都记，见 §12.4）、第一次观察到的生物 / 行为、暴风雨、漂流瓶被打开、
  椰子落海、小惊喜事件等。
- **只追加，永远不会被 Undo 撤销；Reset World 时默认保留**（那是这片海的经历，不是用户的操作）。
- 单独存储（不放在 Save World 槽里），设上限（比如保留最近 300 条，旧的按天合并成一句摘要）。

### 11.2 我的海洋 My Ocean —— 我在这里创造了什么
- 例如：新岛诞生、放了一片珊瑚、改造了一片海床。
- **关键技术决定：不要做成事件日志，而是由「当前世界状态」推导出来。**
  每个创造物自己带 `bornAt`（时间戳）和自动生成的名字（如「雨天下午诞生的小沙洲」）；
  日记渲染时遍历当前世界里的创造物生成条目。这样 Undo / Redo / Reset / 读档后**天然一致**，不需要同步日志。
- 注意：现在的 Island Stamp 只改地形（`sed` 的 `firm` 层），**没有「岛」这个实体**。
  需要新增岛屿实体记录（中心、半径、bornAt、名字），并纳入 `HistoryManager` 的撤销 / 重做和存档。
- 名字可以让用户点一下改；不改也完全没关系。

### 11.3 不打扰
- 有新条目时**没有红点、没有弹窗、没有声音**；日记只是在那里，用户想看时打开。

## 12. P3 — 稀有访客 + 观察手记 Field Notebook

### 12.1 两类生物
- **常驻生物**：一直在鱼缸里，有固定活动范围，长期属于这个生态（就是 v1 现有的生物）。
- **稀有访客**：临时来、待一会儿、离开；有出现条件和偏好的时间段，**可预期而不是纯随机**——
  用户知道「海龟傍晚常来」，就会想「下次傍晚看看」，而不是焦虑地一直盯着屏幕。

### 12.2 物种表与频率（开发侧必须完整定义；**UI 里不显示总数**）

**常驻生物（v1 已有，11 种）**——第一次被用户点到 / 悬停观察时写入观察手记：

| 物种 | 默认数量（上限） | 活动范围 |
|---|---|---|
| 银汉鱼 silverside（鱼群） | 44（90） | 中层开阔水域，鱼群 |
| 天竺鲷 cardinal（鱼群） | 16（40） | 礁区附近 |
| 小丑鱼 clownfish | 3（6） | 海葵周围 |
| 蓝倒吊 blue tang | 4（8） | 礁区游荡 |
| 蝴蝶鱼 butterflyfish | 3（8） | 珊瑚附近 |
| 神仙鱼 angelfish | 2（6） | 礁区，慢 |
| 水母 moon jelly | 4（8） | 中上层漂浮 |
| 螃蟹 crab | 2（4） | 海床，永不上岸 |
| 寄居蟹 hermit crab | 1（3） | 海床，会换壳 |
| 鳐鱼 stingray | 1（1） | 海床上方滑翔 |
| 章鱼 octopus | 1（1） | 洞穴 / 珊瑚，会伪装、喷墨 |

**稀有访客（V2 新增，建议 6–8 种，下面是建议值，可微调但要在 README 里写清最终值）**
频率按**有效运行时间**计（页面隐藏 / 壁纸暂停不累计，和漂流瓶一致）。

| 访客 | 出现条件 / 偏好 | 平均间隔（有效运行时间） | 停留 | 在哪里、做什么 |
|---|---|---|---|---|
| 绿海龟 sea turtle | 傍晚（游戏内 16–19 点）概率 ×2 | 约 60–90 分钟 | 5–8 分钟 | 慢慢游进来，啃海草，浮到水面换气 |
| 蝠鲼 manta ray | 夜晚；满月更常见 | 约 2–3 小时 | 4–6 分钟 | 在开阔水域缓慢翻飞 |
| 海豚群（2–3 只） | 白天，大风过后 | 约 3 小时 | 2–3 分钟 | 在远处后方水面跃出 |
| 鲸鲨 whale shark | 任意时间，极少 | 约 6–8 小时 | 约 3 分钟 | 只在最远的后方深处缓缓游过，近乎剪影；用上扩展后的纵深 |
| 海马 seahorse | 白天 | 约 2 小时 | 20–40 分钟 | 卷在海草上，很难发现（适合用放大镜找） |
| 乌贼 cuttlefish | 黄昏 | 约 2 小时 | 4–6 分钟 | 在礁区附近悬停，身体变色 |
| 海鳗 moray eel | 任意 | 约 2 小时 | 约 10 分钟 | 从礁石缝里探头，缓慢张合嘴 |
| 飞鱼 flying fish | 风速 > 50 | 约 1.5 小时 | 1 分钟 | 一小群从水面掠过 |

另外现有的「来访鱼群」小惊喜（fusilier）也算作访客，计入观察手记。

**全局规则**
- 同一时间最多 1 种稀有访客；两次访客之间至少间隔 20 分钟。
- 面板里一个开关：访客 关 / 少 / 正常（「少」= 间隔 ×2），默认「正常」；同步到 Lively 属性。
- 访客是安静的：不吓跑常驻生物（顶多让鱼群让一让路），不发出声音。

**可观察的行为**（第一次看到时写入观察手记）：寄居蟹换壳、章鱼喷墨、章鱼伪装、螃蟹捡食、
鱼群被水流冲散后重组、海龟换气、乌贼变色等。具体列表由实现者整理，写进 README。

### 12.3 观察手记 Field Notebook
- **只有被用户观察到的东西才有一页**：点到或悬停在生物上 ≥ 1 秒算「观察到」。
- **不显示总数、不显示还没发现的剪影、没有完成度**；用户不知道一共有多少页。
- 每页：手绘风的小插图（用离屏渲染该物种的实时模型，复用放大镜的离屏渲染思路），双语名字、
  两三句温柔的知识小注，以及「第一次见到：某天傍晚」。
- 页面按发现顺序排列，像真正的手记本。

### 12.4 不会错过（防止 check-in 冲动的关键设计）
- 用户不在、或在看别处时来过的访客：在**世界记忆**里记一句「一只海龟在下午来过」，并在世界里留下
  **痕迹**（沙上的爪印、被啃过的海草、一片乌贼骨……），几小时后自然消失。
- 但**只有亲眼观察到**才会进入观察手记——不会因为错过而被惩罚，只是这次没遇到。
- 访客停留时间足够长（见表），遇到时是从容的惊喜，不是抢时间。

## 13. P4 — 岛屿种子（Island Builder 缩小版）

- 在 Top View 选一片海域 → 放下一颗「岛屿种子」。种子类型（preset）：沙洲、礁石岛、环礁、微型山岛。
- 种子先长成光秃的地形（复用 Island Stamp 和地形系统），之后**按真实时间（时间戳，类似 `CoconutGrowth`）自己慢慢长**：
  几小时到几天里陆续长出草、灌木、小椰子树；螃蟹 / 寄居蟹可能自己搬去住。
- **用户不需要做任何维护**：没有浇水、没有资源、没有失败。用户只是偶尔回来发现「它长了」。
- 少量可摆放的小物件（栈桥、灯塔、吊床、小船）可选；**不做建筑经营系统**。
- 每座岛都是 §11.2 的岛屿实体（有名字、bornAt），自动出现在「我的海洋」里；Undo / Reset 自然一致。
- 世界里岛屿数量设上限（例如副岛 + 用户岛合计 ≤ 8），保住大片空白水域。
